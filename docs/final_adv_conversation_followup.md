# FAB 간 비교·대화 저장 후속 개선

> 후속 업데이트: 사용자 승인 후 외부 모델 재시험을 완료했다. 현재 결과는
> [실모델 재시험 기록](final_adv_live_model_retest.md)을 참고한다. 아래 검증·차단 설명은 승인 전 기록이다.

2026-09-12 · `feat/final_adv` · 기존 4시간 개선 이후의 추가 요청을 반영했다.
기존 작업 트리 변경을 보존했으며 커밋·푸시는 하지 않았다.

사진의 거절 문장은 세션 유실만의 문제가 아니었다. Intent/Planner에 있던 단일 FAB 제한이
명시적인 FAB11·FAB13 비교도 막고 있었다. 별도로 브라우저 대화는 sessionStorage에 저장되어
탭을 닫으면 목록과 서버 대화 ID가 사라질 수 있었다.

## 반영한 동작

- FAB10~13 중 2~4개 FAB을 같은 관측 시각으로 조회하고 공정별 차이를 계산한다.
  범위·시각·공정 영역이 맞지 않으면 전체 비교로 단정하지 않는다.
- “방금 조회한 두 FAB”은 성공한 사용자 질문의 범위에서 복원한다. 이전 답변의 예시 FAB이나
  실패한 요청으로 대상을 바꾸지 않는다. “어제와 오늘 비교”를 FAB 간 비교로 오인하지 않는다.
- FAB 전체 추세는 FAB별 선으로, 명시적으로 공정별 추세를 요청하면 FAB·공정별 선으로 표시한다.
- 브라우저 대화는 IndexedDB에 저장하고 기존 저장 내용을 이관한다. 대화 ID는 응답 시작 시점부터
  보존한다. IndexedDB 사용 불가 시 localStorage로 대체한다. 초안과 활성 대화도 유지한다.
- 본문은 운영 지표·관측 시각·단위를 중심으로 답한다. 반복적인 생성 데이터 설명은 접힌
  `데이터 출처 정보`와 내보낸 보고서에 보존한다. 실시간 측정이라고 주장하지 않는다.
- 기존에 저장된 답변은 과거 기록 그대로 남는다. 새 답변부터 변경된 표현이 적용된다.

## 사진 질문의 확인 결과

2026-09-12 00:00 KST 기준 FAB11은 188 LOT, FAB13은 159 LOT이며 차이는 29 LOT이다.
공정별 차이(FAB11 − FAB13)는 CMP +62, Photo −48, Etch +6, Deposition +5,
Implant +4, Metrology 0 LOT이다.

차이가 가장 큰 CMP에서 FAB11/FAB13의 대기 시간은 41.65/12.35분, 가동률은
73.23/79.04%, 정비 시간은 17/0분이었다. 이 관측 상태를 우선 확인할 대상으로 설명하고,
정비·대기가 재공 차이를 일으켰다는 인과 결론은 시각이 정렬된 이력 없이 단정하지 않는다.

5턴은 FAB11 WIP → FAB13 WIP → 사진의 비교·진단·시각화 질문 → “방금 조회한 두 FAB” →

모든 모델 호출과 HTTP 전송을 차단하고 localhost DB SELECT만 사용했다. 이 결과는
실모델의 자연어 생성 성능이나 브라우저에서 모델까지 연결한 종단 간 성공률이 아니다.

이전 자동 승인 검토가 공정 데이터·문서 근거의 외부 모델 전송을 거절한 상태이므로,
이번 수정본의 외부 모델 재시험은 수행하지 않았다. 추가 전송 범위 확인은 기존 요청대로 남아 있다.

각 답변·SQL·근거는 같은 폴더의 `comparison_local_final.json`에 있다.
